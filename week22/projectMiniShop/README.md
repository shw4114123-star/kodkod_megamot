# project mini shop


### הוראות הרצה 
 
הורדת הפרויקט = *git clone*
התקנת הסיפריות = *pip install*
הרצת האתר = *npm run dev*
##


### Hooks = useFetch - השתמשתי בשביל לשלוף את הנתונים פעם אחת בשביל כל הפרויקט
### context = ThemeContext - השתמשתי בשביל השינוי בין dark mode ל light mode
### zostand = product.ts - השתמשתי בשביל לאחסן את הנתונים ולשלוף אותם בכל מקום שאני צריך בלי להעביר מאבא לבן ולשלוף נתונים בחיפוש ולשלוף נתונים בשביל המועדפים
